# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue: go to the repository's **Security** tab and choose
**Report a vulnerability** (GitHub private vulnerability reporting). Only the maintainer sees the report.

Include what you found, how to reproduce it, and which version you use.

## Supported versions

Only the latest release gets fixes. Please update before reporting.

## What to expect

- A first reply within a week.
- A fix in a new release as soon as it is ready, with the problem described in the [CHANGELOG](CHANGELOG.md) once the
  fix is out.
- Credit in the release notes if you want it.

This is a hobby project maintained by one person, so these are goals, not guarantees.
